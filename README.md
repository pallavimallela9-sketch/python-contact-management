# Contact Management System

This Python program is a contact management application that allows users to store and manage contact information.

## Features

* Add new contacts
* Store phone number, email, and city
* View all contacts
* Search contacts by name
* Update contact information
* Delete contacts
* Display contact summary
* Menu-driven interface

## Technology Used

* Python

## Concepts Used

* Dictionaries
* Nested dictionaries
* `while` loop
* `for` loop
* Conditional statements
* String methods
* Dictionary operations
* User input
* Menu-driven programming
